# IDEAS - Horizon Shopping

Este documento recoge ideas y posibles funcionalidades para futuras versiones de Horizon Shopping.

Las propuestas aquí registradas no forman parte necesariamente del desarrollo actual ni tienen una fecha de implementación asignada.

Las ideas se evaluarán según su utilidad, complejidad técnica, prioridad y compatibilidad con la arquitectura existente.

## Gestión de productos y compras

- Añadir lectura de códigos de barras para facilitar la incorporación de productos.
- Crear una lista de productos favoritos.
- Registrar productos frecuentes para agilizar la creación de listas.
- Incorporar el precio individual de los productos.
- Calcular automáticamente el total de la compra.
- Comparar precios entre establecimientos.

## Compartición

- Permitir compartir listas o vincular dispositivos mediante códigos QR como alternativa al código numérico actual.

## Exportación

- Exportar listas de la compra a PDF.
- Exportar listas de la compra a Excel.

## Integración con Android

- Incorporar widgets para consultar o gestionar la lista desde la pantalla de inicio del dispositivo.

## Recetas

- Permitir gestionar recetas de cocina.
- Generar listas de la compra a partir de los ingredientes de una receta.
- Facilitar la incorporación de ingredientes a una lista existente.

## Criterios de evaluación

Antes de implementar una idea, se valorará:

- Su utilidad para el usuario.
- La complejidad de desarrollo y mantenimiento.
- La compatibilidad con la sincronización entre dispositivos.
- El impacto sobre la arquitectura y la persistencia.
- La prioridad frente a las tareas pendientes del `ROADMAP.md`.
